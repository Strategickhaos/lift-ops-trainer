# Evolution path

1. **Now** – single-file HTML on phone + this repo skeleton.
2. **Next** – Flash (tachistoscope) tab driven from content/flashcards/*.yaml.
3. **Then** – Termux / CLI renderer.
4. **Later** – custom training DSL (lexer → parser) or direct FlameLang surface.
5. **SAGCO integration** – agent renderer that emits prompts / JSA fragments from the same AST.

The content tree is the durable asset. Renderers come and go.
